STAGE 1: COLLECTOR (collect/uba5.sh)
  1. systemd: EXPECTED_UNITS at the top. For each: is-active, is-enabled,
     ActiveEnterTimestamp, NRestarts; "EXPECTED BUT not active/enabled" stands out.
     Failed units and timers stay as they are.
  2. New section ota (after docker):
       - hdhr-ac4: HTTP codes for :8080/, :8080/discover.json, :5004/; its HDHR_IP
         (only that variable from the container's env).
       - tuner(s) in TUNER_IPS at the top: ModelNumber, FirmwareVersion, TunerCount,
         tuners in use; UNREACHABLE after 5 s. "HDHR_IP MISMATCH" if hdhr-ac4 points
         at an address not in TUNER_IPS.
       - SiliconDust devices (MAC 00:18:dd) in the ARP table, so a moved tuner shows
         its new address.
  3. New section security (after ota):
       - load average and the top 5 processes by CPU (user, pid, %cpu, elapsed, name).
       - established TCP connections per user, LAN vs outside (own IPv6 /64 = LAN);
         "UNEXPECTED OUTBOUND" for a user with outside connections who is not in
         OUTBOUND_OK_USERS. Counts only, no outside addresses.
       - executable files in /tmp, /var/tmp, /dev/shm owned by a system account
         (uid 1-999 or nobody): owner, size, mtime, path, flagged
         "UNEXPECTED EXECUTABLE".
       - Plex stays gone: package installed?, unit active?, processes as user plex;
         "PLEX IS BACK" if any.
  4. redact.sh: an absolute system path (/usr, /etc, /var, /home, /opt, /snap, ...)
     is checked one path segment at a time instead of as a whole, so long paths
     survive while a long secret-looking segment is still redacted. Selftest: a keep
     sample (long path) and a leak sample (secret as a path segment). X-Plex-Token
     values are already caught by the generic token rule.
